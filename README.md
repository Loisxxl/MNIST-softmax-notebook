# MNIST 手写数字分类：Softmax 回归
使用 PyTorch 对 MNIST 灰度手写数字图像（28×28，数字 0–9）进行分类。模型将图像展平为 784 维向量，并通过线性层输出 10 类分数。
## 环境
- Conda 环境：`mnist`
- Python：3.11.18
- PyTorch：2.14.1+cpu
- torchvision：0.29.1+cpu
- 运行设备：CPU
依赖：PyTorch、torchvision、NumPy、Matplotlib。
## 数据与训练设置
- MNIST 训练集：60,000 张；测试集：10,000 张
- 模型：`Flatten → Linear(784, 10)`，共 7,850 个参数
- 损失函数：交叉熵（`CrossEntropyLoss`）
- 优化器：SGD，学习率 0.1
- 批次大小：256；训练轮数：10；随机种子：42
## 复现结果
以下结果来自本次 Jupyter 复现：
- 第 1 轮训练损失：0.7143；第 10 轮：0.3116
- 第 10 轮训练准确率：91.34%
- 测试损失：0.2983
- 测试集预测正确：9,172 / 10,000
- **测试准确率：91.72%**
- 随机抽取的 20 个测试样例中，19 个预测正确
